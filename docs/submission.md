# Данные внешнего стенда для сдачи

Исходный архив содержит рабочий проект и локальные протоколы проверки. Следующие поля заполняются после создания собственного репозитория и реального запуска GitHub Actions на вашей ВМ:

| Поле | Значение |
| --- | --- |
| URL Git-репозитория | Заполнить после публикации |
| URL pull request | Заполнить после создания PR |
| URL успешного Actions run | Заполнить после выполнения workflow |
| SHA коммита main | `git rev-parse HEAD` на опубликованной ветке |
| Образ GHCR | `ghcr.io/<владелец>/<репозиторий>:<полный SHA>` из job publish |
| Digest развёрнутого образа | `docker image inspect <образ> --format '{{json .RepoDigests}}'` |
| Идентификатор предыдущего образа | `.deploy/previous-image` на стенде |
| Дата демонстрации отката на ВМ | Заполнить после проверки |
| Фактически затраченное время практики | По собственному журналу |

Наличие workflow в архиве не означает, что удалённый Actions run уже выполнен. Локальная проверка не заменяет обязательную демонстрацию pipeline на подключённом runner. Порядок настройки приведён в README.
